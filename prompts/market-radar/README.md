# Market Radar

这个文件夹用于维护市场温度和主线识别框架。

每次研究市场，先判断市场温度，再识别主线。

## 1. A股市场温度

需要观察：

- 上证指数
- 深成指
- 创业板指
- 科创50
- 北证50
- 成交额
- 涨跌家数
- 涨停数量
- 连板高度
- 炸板率
- 板块强度
- 融资余额
- ETF资金
- 人民币汇率
- 政策和监管信号

## 2. 美股与全球风险偏好

需要观察：

- 纳斯达克
- 标普500
- 道琼斯
- SOX半导体指数
- VIX
- 美债收益率
- 美元指数
- 英伟达
- 博通
- AMD
- 台积电
- 美光
- SK海力士
- 日股
- 韩股
- 台股
- 港股

## 3. 主线识别

不要默认AI永远最强。

根据以下信号判断真正主线：

- 涨幅
- 成交额
- 涨停数量
- 板块持续性
- 龙头强度
- 海外映射
- 政策催化
- 财报 / 公告
- 行业新闻
- 资金流向
- 机构抱团程度
- 短线情绪强弱

- AI算力
- 光模块 / CPO
- HBM / 存储
- 半导体设备材料
- 创新药
- 机器人

- 液冷
- 固态电池
- 新能源
- 有色
- 军工
- 消费
- 金融
- 低空经济
- 核电
- 算力租赁
- 国产软件
- 出海链

## 5. 市场状态标签

每次判断市场时，用以下标签之一：

- 主升
- 震荡
- 轮动
- 分歧
- 退潮
- 杀估值
- 杀逻辑
- 情绪修复
- 弱反弹
- 强修复

## 6. 输出要求

每次市场雷达输出必须包含：

1. 总市场状态
2. A股温度
3. 美股 / 全球风险偏好
4. 当前最强主线
5. 次强主线
6. 退潮主线
7. 潜伏主线
8. 是否适合进攻
9. 是否适合只观察
10. 下一步重点跟踪

# Stock Research System

这是我的股票研究总控仓库。

目标：把 ChatGPT / 深度研究 / GitHub 开源项目 组合成一个股票研究系统，用于：

- 实时市场温度判断
- 当前主线识别
- 产业链穿透
- 木桶效应 / 供应链瓶颈挖掘
- A股 / 美股股票池分层
- B1 与单针下20交易过滤
- 风险反证和复盘

## Folder Structure

### prompts
存放股票研究系统 Prompt 和深度研究 Prompt。

### market-radar
存放市场温度、主线识别、全球风险偏好观察框架。

### repos-watchlist
存放已 fork 的 GitHub 股票研究相关项目索引。

### stock-pool
存放股票池分层规则和观察池。

### skills
存放从外部项目里提炼出来、适合我自己的研究 skill。

### notes
存放日常研究笔记、复盘和临时想法。

## Core Workflow

1. 先看市场温度
2. 再识别市场主线
3. 主线产业链拆解
4. 木桶效应寻找瓶颈
5. 股票池分层
6. 单只股票六问
7. B1 / 单针下20 交易过滤
8. 估值、涨幅、风险反证
9. 下一步跟踪清单

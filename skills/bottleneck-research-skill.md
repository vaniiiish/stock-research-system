# Bottleneck Research Skill

这个 skill 用于训练股票研究时的木桶效应思维。

核心目标：

看到一个产业主线，不要只找最大龙头，而要寻找产业继续扩张时最先不够用的环节。

## 1. 核心问题

看到一个产业主线时，必须问：

1. 产业继续扩张时，哪个环节最先不够？
2. 这个不够是短期供需错配，还是长期结构性瓶颈？
3. 扩产难不难？
4. 客户验证周期长不长？
5. 技术门槛高不高？
6. 有没有价格弹性？
7. 有没有国产替代空间？
8. 哪些公司真的卖这个东西？
9. 收入占比多少？
10. 市场是否已经充分定价？

## 2. 产业链穿透方法

不要停留在一级概念。

### AI算力示例

AI模型 → GPU / ASIC → HBM / DRAM → 先进封装 → 光模块 / CPO → PCB / 基板 → 服务器 → 数据中心 → 电力设备 → 液冷 → 上游材料和设备

### 创新药示例

疾病需求 → 靶点 → 药物机制 → 临床阶段 → 适应症 → BD交易 → 商业化 → 医保 → CXO → 上游试剂

### 机器人示例

整机 → 控制器 → 执行器 → 减速器 → 丝杠 → 传感器 → 电机 → 材料 → 工艺 → 客户认证

## 3. 瓶颈评分

每个环节按照以下维度打分：

- 需求确定性
- 供给约束
- 扩产难度
- 验证周期
- 技术壁垒
- 价格弹性
- 国产替代空间
- 公司收入占比
- 市场认知差
- 股价是否透支

## 4. 公司验证

每个公司必须验证：

- 是否真的做这个产品
- 是否有产能
- 是否有客户
- 是否有公告证据
- 是否有财报收入
- 是否有订单
- 是否有技术认证
- 是否有扩产计划
- 是否只是概念映射

## 5. 输出格式

每次输出：

1. 主线
2. 产业链地图
3. 3-10个木桶短板
4. 每个短板对应公司
5. 证据强弱
6. 收入占比
7. 股价是否透支
8. 风险反证
9. 下一步跟踪

## 6. 研究纪律

社交媒体、推特、雪球、论坛只能作为线索。

强结论必须回到：

- 公司公告
- 财报
- 交易所披露
- 招股书
- 投资者关系
- 客户认证
- 订单
- 产能
- 行业数据

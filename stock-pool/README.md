# Stock Pool Rules

这个文件夹用于维护股票池分层规则、观察池、交易状态和个股验证逻辑。

## 1. 股票池分层

### S级

直接受益，收入、订单、利润已经兑现。

特点：

- 产业逻辑强
- 财务已经验证
- 客户或订单明确
- 市场认可度高

风险：

- 可能估值已经不便宜
- 可能交易拥挤
- 不一定有舒服买点

### A级

关键瓶颈环节，有客户验证、产能或明确订单，但利润还没完全释放。

特点：

- 木桶短板环节
- 有客户认证或产能证据
- 存在业绩释放预期
- 有预期差

风险：

- 利润兑现可能慢
- 收入占比可能还不高
- 股价可能提前炒作

### B级

逻辑成立，但收入占比、客户认证、利润弹性还需要验证。

特点：

- 产业映射有逻辑
- 市场可能开始关注
- 适合观察和等待证据

风险：

- 容易变成概念炒作
- 可能没有真实收入
- 需要公告和财报验证

### C级

概念映射，市场可能会炒，但基本面证据不足。

特点：

- 题材相关
- 可能短线活跃
- 基本面证据弱

风险：

- 不适合重仓
- 不适合当核心池
- 只适合观察情绪

### 暂不考虑

进入暂不考虑的原因包括：

- 涨幅过大
- 估值严重透支
- 逻辑不清
- 没有真实业务证据
- 主线退潮
- 技术结构走坏
- 业绩和题材不匹配

## 2. 单只股票六问

每只股票必须回答：

1. 它卖什么？
2. 卖给谁？
3. 为什么这个东西可能紧缺？
4. 这部分业务收入占比多少？
5. 有没有公告、财报、客户认证、订单、项目、专利、产能等证据？
6. 现在股价是否已经透支？

## 3. 交易状态标签

### 观察中

逻辑成立，但买点未出现。

### 接近触发

逻辑成立，技术结构接近买点，需要继续确认。

### 可模拟买入

逻辑、主线、技术结构、风险收益比都比较匹配，可以进入模拟账户观察。

### 暂不考虑

逻辑不清、位置太高、主线退潮、估值透支或技术结构走坏。

## 4. 交易过滤

上涨趋势不是坏事。

强趋势票可以重点观察，但不能无脑冲。

优先顺序：

1. B1回调确认
2. 强趋势趋势跟随
3. 单针下20补票信号
4. 连续高潮后的风险回避

## 5. B1框架

B1是优先级更高的右侧低吸 / 回调确认方式。

使用前提：

- 大盘环境不能太差
- 板块主线仍然强
- 个股处于趋势结构中
- 回调健康
- 量能没有失控
- 价格没有明显虚高
- 右侧确认出现

## 6. 单针下20

单针下20是辅助补票信号。

适用场景：

- 主线强
- 个股是强趋势
- 没有给明显B1回调
- 错过上车点
- 长期资金没有真正走坏
- 短期资金 / 散户情绪快速下杀到20 / 30甚至更低
- 次日长期资金快速拉回，并带动短期资金修复
- 出现放量长阳修复

注意：

单针下20不能单独作为买入理由。

必须结合：

- 主线强度
- 个股趋势
- 量能
- 估值
- 价格位置
- 次日确认
- 大盘环境

## 7. 强趋势处理原则

不是不追涨。

正确原则是：

- 不追无结构高潮
- 可以跟踪强趋势
- 强趋势票如果产业逻辑、主线强度、量价结构和估值还能支撑，可以进入观察池
- 买点优先等B1
- 如果没给B1，再观察单针下20或其他强趋势补票信号
